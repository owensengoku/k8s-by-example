# Kubernetes by Example

This repository contains a collection of example Kubernetes manifest files. These examples are intended to help users understand various Kubernetes concepts and resources.

## Directory Structure

The repository is organized into the following main directories under `specs/`:

*   `configmaps/`: Examples of ConfigMaps, which are used to store non-confidential data in key-value pairs.
*   `deployments/`: Examples of Deployments, which manage stateless applications.
*   `labels/`: Examples demonstrating the use of labels for organizing Kubernetes objects.
*   `logging/`: Examples related to logging configurations for Pods.
*   `pods/`: Examples of Pods, the smallest deployable units in Kubernetes.
*   `probes/`: Examples of liveness and readiness probes for container health checks.
*   `services/`: Examples of Services, which expose applications running on a set of Pods as a network service.

Each subdirectory contains YAML files demonstrating specific use cases and configurations for the respective Kubernetes resource.
